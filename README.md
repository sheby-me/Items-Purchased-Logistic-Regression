# Items-Purchased-Logistic-Regression
## Project Overview
This Machine Learning project predicts whether a customer will purchase an item or not based on their features using **Logistic Regression**.

---

## Problem Statement
Given customer data (such as age, salary, etc.), the model predicts:
- 1 → Customer will purchase the item
- 0 → Customer will NOT purchase the item

---

## Algorithm Used
- Logistic Regression (Supervised Learning - Classification)

---

## Dataset
The dataset contains customer-related features such as:
- Age
- Estimated Salary
- User behavior data (if available)

---

## Tech Stack
- Python 🐍
- Pandas
- NumPy
- train-test-split
- Scikit-learn

---

## Workflow
1. Data Collection
2. Data Preprocessing
3. Train-Test Split
4. Model Training (Logistic Regression)
5. Prediction
6. Accuracy Evaluation

---

## Model Performance
- Accuracy Score: *87%*  
- Evaluation Metrics: Accuracy Score
